# KDTIME 새 UI 화면 규칙

새 UI(다크·라이트)에서 화면을 추가하거나 고칠 때 지키는 규칙입니다. 기존 UI 모드는 이 규칙의 대상이 아닙니다.

## 1. 한 화면, 한 가지 이동 수단
- 같은 곳으로 가는 버튼을 두 군데 이상 두지 않습니다.
- 학생 작업 줄(성적 리포트 · 개인 시간표 · 광덕고 대입 결과 | 대학 탐색 · 관심대학·상담 · NAVI 분석)이 기본 이동 수단입니다.
- 화면 안의 단계 카드나 바로가기 버튼이 같은 이동을 하면 새 UI에서는 숨깁니다(`kdn-hide-new`, `kdn-dup-nav`).

## 2. 강조색(주황)은 화면당 주요 행동 1개
- 꽉 찬 주황 버튼은 그 화면의 다음 행동 하나에만 씁니다(예: "다음: 대학 상세 n건 보기").
- 보조 행동(인쇄, 돌아가기, 바로가기)은 테두리 버튼입니다.
- 선택된 상태(탭, 토글, 회차)는 주황 테두리 + 옅은 주황 바탕입니다. 꽉 찬 주황으로 칠하지 않습니다.

## 3. 눌러지는 것은 경계가 보이게
- 버튼은 항상 1px 테두리가 보입니다. 테두리 없는 버튼은 `uiMode.js`가 자동으로 `--kdn-control-line` 테두리를 붙입니다.
- 글자 링크나 메뉴 항목처럼 테두리가 없어야 하는 버튼은 `data-kdn-bare`를 붙입니다.

## 4. 상자는 정보 묶음당 하나
- 같은 주제의 검색·필터·적용 조건은 한 상자(툴바)에 넣습니다. 상자 안에 상자를 겹치지 않습니다.
- 반복 안내 문장은 한 번만 보여 줍니다. 빈 칸 6개에 같은 안내를 6번 쓰지 않습니다.

## 5. 글자
- 핵심 숫자·이름은 가장 진한 글자색, 보조 설명만 회색입니다.
- 이름표는 13px 이상, 본문은 14px 이상입니다(12.5px 미만은 엔진이 자동으로 키움).
- 설명 문장은 한 줄을 넘기지 않습니다. 길면 `details`(접기)로 옮깁니다.

## 6. 인쇄
- 화면 규칙은 인쇄물에 영향을 주지 않습니다. 인쇄용 요소는 `kdn-print-only`로 남깁니다.
- 수시지원 상담 카드는 인쇄 직전에 카드마다 높이를 재서, 넘치는 카드만 단계적으로 줄입니다(`fitPrintCards`).
